ppt-compress re-encode ratios

Each image is re-encoded the way the engine does it, keeping the original when the candidate is no smaller. A ratio is the bytes left over the bytes going in; model is what the estimator (src/lib/ppt/pptCompressPlan.ts, as checked out) expects.

  • Fresh JPEG curve: lossless originals (PNGs under tests/lossless, and the HEIC fixtures) saved by this browser as fresh JPEGs at each quality, then re-encoded at each preset.
  • Real-file images: each image in the real-file decks and each loose JPEG/PNG (deduplicated by bytes and display size). Like the engine, a preset that downsamples first shrinks a picture to its display size (read by src/lib/ppt/displaySize.ts) with the engine's resizer (src/lib/image/downscale.ts); a loose image has no display size and keeps its pixels. fresh → P is the image as found, re-encoded at preset P; W → P is the image after the engine compressed it at weaker preset W, re-run at P, skipped when W left it unchanged or (PNG) wrote it indexed, since both already count as compressed.
  • Decks: each real deck's estimate against the size its re-encoded images give, fresh and re-run (a deck compressed at W, then at P). The size ignores the zip's own deflate of the images, which is about 1%. HEIC sets are hold-out "decks" of the HEIC photos at one quality.
  • Resized pictures: each step that resized a picture, its ratio against the model and against today's model for the same picture not resized; kept is the share of its pixels it keeps.
  • High-resolution set: lossless photos larger than any downsampling target, under tests/hires (local only, never committed), to calibrate and hold out the downsampled path: each saved as a fresh q95 and q86 JPEG and kept as its lossless PNG, placed across the full slide width and half of it, beside the loose real-file photos placed the same way, then run through every step. Source: the 8-bit RGB set of imagecompression.info test images (PPM, converted to PNG by ppm-to-png.mjs). Query ?parts=curve,heic,png,fixtures,hires,analysis picks what to run (default all but hires and analysis, which run only when named). png re-encodes the lossless originals as fresh PNGs, as found and as this browser saves them. analysis times the tool's idle-time analysis of each real deck (analyzePptxForCompress) against the part of it that reads the slides for display sizes, and shows how each deck's picture bytes spread over the scale each preset would resize them to.
