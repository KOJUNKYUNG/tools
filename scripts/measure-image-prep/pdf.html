image-to-pdf picture size measurement

Grilling measurement for image-to-pdf's picture size setting (2026-11-20). Each input set becomes one PDF per level: pictures sized for the page, prepared by the shared preparation image-to-pptx uses (sizedImagePreparation in src/lib/image/slideImage.ts: never enlarged, a whole JPEG at its own size goes in as uploaded, a PNG turns into JPEG only at half the size or less), then embedded with pdf-lib, one picture per page, orientation auto, no margin.

  • original: every picture as uploaded (HEIC after the tool's conversion), a PNG embedded losslessly without growing (embedPng in src/lib/pdf/embedPng.ts, the assembler's, issue #178).
  • original, pdf-lib PNG: the same, every PNG embedded by pdf-lib's embedPng, as the assembler did before issue #178.
  • A4 @ N dpi: the picture holds no more pixels than N dots per inch across the size it is drawn at on A4 (210 × 297 mm, turned to the picture).
  • 16:9 full-hd / 4k: image-to-pptx's screen size on a 16:9 page turned to the picture (containedSize).
  • MB is the whole PDF's size. Pictures not shrunk keep their bytes, so a set of small pictures barely moves.

Every other level embeds PNGs as the assembler does. Query ?sets=jpg,heic,png&dpi=100,150,200,300&screens=full-hd,4k picks what to run.
