pdf-watermark — 개편 시안

요청한 7개 항목의 검토안. 결정이 필요한 항목은 2~3개 변형을 나란히 두었고, 명확한 항목은 §7 최종 조립안에 반영했습니다. 권장 표시는 제 추천안이며 최종은 직접 고르시면 됩니다. §4 페이지번호 드래그는 실제로 끌어볼 수 있습니다.

  • 1 좌·우 패널 구분선 신설 (DESIGN.md에도 규격 추가)
  • 2 기본값 워터마크 + 토글 왼쪽에 워터마크
  • 3 모드 토글의 상위 위계 · 하위 토글 폭 축소
  • 4 미리보기에서 페이지번호 드래그 배치
  • 5 입력 필드 컴팩트 재배열
  • 6 적용페이지 배경 + 버튼 구분(상태/파일열기)
  • 7 상단 스트립을 도구 헤더로 이관 검토

③ 모드 토글 위계 + 하위 토글 폭

현재는 페이지번호/워터마크(모드) · 형식 · 텍스트/로고 세 토글이 모두 full-width 밑줄탭이라 위계가 안 느껴집니다. 세 변형: 모드 토글을 어떻게 상위로 읽히게 할지.

A · 폭만 축소모드=밑줄탭(내용폭) · 하위=내용폭
모드와 하위가 같은 밑줄탭이라 여전히 위계 약함 — 폭만 줄인 최소 변경.
B · 설정 감싸기모드=탭 · 아래 설정을 박스로권장
설정 영역이 박스로 묶여 모드 토글이 그 위 상위 항목으로 읽힘. 하위 토글 밑줄은 버튼 폭만 받침.
C · 세그먼트 필모드=pill · 하위=밑줄탭
모드=pill로 형태 자체가 달라 위계 명확. 단, DESIGN.md는 단일선택=밑줄탭 canon — pill 도입은 계약 확장 필요.

메모 · C의 pill은 지금 canon(모든 단일선택=밑줄탭, filled 금지)과 충돌 → 채택 시 DESIGN.md 개정 필요. B는 canon 유지하며 위계만 부여(박스=구조적 마크). 그래서 B 권장.

9앵커 그리드(우패널) — 클릭 시 해당 프리셋 위치로 스냅(빠른 모서리/중앙 지정). GridPosition 유지.

모델 — 옵션에 정규화 position:{x,y}(또는 grid=custom+offset) 추가. overlayLayout·프리뷰·export가 같은 좌표계 공유. 회전/타일은 페이지번호 모드에선 미적용이라 상호작용 단순.

적용 대상 = 페이지번호 모드(요청 범위). 워터마크 자유배치는 후속 확장 여지.

확정 · 9앵커 프리셋(우패널) + 프리뷰 자유 드래그 병행. 데이터모델에 정규화 좌표 추가 → overlayLayout/export 확장(⑧ 검증에서 회전·경계 클램프 테스트).
