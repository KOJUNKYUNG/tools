# Ontab — 리브랜딩 & 리디자인 설계 문서

- **작성일:** 2026-04-20
- **상태:** 기획 확정 (구현 착수 전)
- **대상 프로젝트:** 현재 저장소 (구 가칭 DocuFlow → **Ontab**)

---

## 1. 배경 & 목적

### 1.1 서비스 기원
본 서비스는 창작자 본인이 매주 반복 수행하는 교회 PPT·문서 작업(배경 일괄 교체, 이미지 리사이즈, 악보 PDF 처리, 슬라이드 이미지 추출 등)의 불편을 해소하려는 개인 필요에서 출발했다. 기존 대체 서비스(iLovePDF, ppt.ai 등)는 서버 업로드 속도·일일 처리 제한·배경 교체 미지원 등의 불편이 있어, **브라우저에서 완결되는 무제한 문서 도구 모음**으로 재정의한다.

### 1.2 이번 작업의 목적
현재 MVP(10개 도구, 한국어 전용, 가칭 DocuFlow) 상태에서 다음을 수행한다:

1. 서비스 브랜드 확정 (**Ontab**)
2. "책상 위 도구" 컨셉 기반 전면 리디자인
3. 한국어 + 영어 i18n 인프라 도입
4. 브라우저에서 구현 가능한 신규 도구 대폭 확장
5. 각 도구의 IMPROVEMENTS.md 개선 항목 반영

### 2.1 핵심 차별점
- **100% 브라우저 처리** — 서버 전송 없음, 파일 일 제한 없음
- **PPT 일괄 배경 교체** — 경쟁 서비스 미제공
- **PPT 이미지 추출** — 원본 품질 유지
- **무료·무제한·무로그인**

## 3. 디자인 시스템

### 3.1 비주얼 톤
- **메인 톤:** 따뜻한 우드톤 + 깔끔·전문적 (빈티지·낡은 느낌 배제)
- **메타포:** 카테고리 탭 = 공구 상자 / 개별 도구 = 책상 위 문구·공구
- **목표 인상:** "잘 정돈된 장인의 작업 책상에서 필요한 도구를 바로 집어 쓴다"

### 3.2 컬러 팔레트 (초안 방향)
- **베이스:** 오프화이트 / 크림 / 연베이지
- **악센트:** 원목 브라운 / 머스터드 / 딥 그린
- **포인트:** 진한 우드 / 먹색
- **다크모드:** 딥 브라운 + 크림 베이스로 파생
- (정확한 HEX 값은 구현 단계에서 확정)

### 3.3 타이포 & 아이콘
- **타이포:** 기존 Geist 계열 유지 검토 또는 한/영 모두 어울리는 세리프·산세리프 조합
- **아이콘:** `lucide-react` 유지 + 일러스트(책상·선반·문구) 별도 자산 제작

### 3.4 기기 우선순위
- **데스크톱 1급(1280+):** 풀 UI·인터랙션 최적화
- **모바일:** 반응형 동작 보장, 고도 인터랙션(PDF 페이지 DnD, PPT 배경 편집 등)은 데스크톱 권장 안내

## 4. 정보 구조 & 랜딩

### 4.1 메인 네비게이션 (3축)
1. **프레젠테이션** — PPT·슬라이드 특화 도구 (간판 카테고리)
2. **문서** — PDF 도구
3. **이미지** — 이미지 처리 도구

각 탭은 "공구 상자"로 시각화한다.

### 4.2 랜딩 페이지 구성
```
[ Header ] Ontab 로고 · 3축 네비 · 언어 토글 · 다크모드
[ Hero ]
  - 책상·선반·문구가 배치된 일러스트
  - 슬로건(KR/EN)
  - CTA: 카테고리 바로가기
[ Tool Shelves ]
  - 3개 섹션(프레젠테이션 / 문서 / 이미지) = 3개 "선반"
  - 각 선반에 도구 카드 그리드(카드는 문구/공구 아이콘 + 이름 + 설명)
[ Value Props ]
  - 서버 전송 없음 / 무제한 / 무료 / 오픈소스
[ Footer ]
```

## 5. 기술 인프라

### 5.1 유지
- Next.js 16 (App Router), React 19, TypeScript 5
- Tailwind CSS 4 + shadcn/ui (재테마 예정)
- pnpm
- 기존 도메인 라이브러리 (`pdf-lib`, `pdfjs-dist`, `@kihyun1998/justpdf-compress-wasm`, `jszip`, `cfb`, `browser-image-compression`, `@dnd-kit/*`)

### 5.2 신규 도입
- **i18n:** `next-intl` (한국어 + 영어 동시 지원, 카피 전부 번역 키로 분리)
- **shadcn 재테마:** 우드 팔레트 커스텀 토큰
- **일러스트 자산 세트:** 책상·선반·문구·도구 아이콘 SVG

### 5.3 도입 보류
- **Clerk (로그인):** 본 로드맵에서 제외. 필요 시 Post-Ontab 단계에서 재검토.
- **Supabase (DB/Storage):** 본 로드맵에서 제외. 갤러리는 현행 Mock 유지 후 추후 재검토.
- **결제·유료 티어:** 없음.

## 6. 도구 로드맵

> 원칙: "브라우저에서 구현 가능한 건 대부분 포함한다". 서버 측 처리가 필요하거나 품질이 낮은 도구는 제외.

### 6.1 기존 10개 (리디자인 + 개선 마이그레이션)
| 기능 | 경로 | 개선 포인트 |
| :--- | :--- | :--- |
| 이미지 → PDF | `/tools/image-to-pdf` | 공통 "다시 작업하기" |
| PDF → 이미지 | `/tools/pdf-to-image` | 동일 |
| PDF 합치기 | `/tools/pdf-merge` | DnD 순서 변경 UI 추가 |
| PDF 압축 | `/tools/pdf-compress` | 공통 "다시 작업하기" |
| PDF 분할 | `/tools/pdf-split` | 동일 |
| PDF 페이지 관리 | `/tools/pdf-pages` | 동일 |
| PPT 이미지 추출 | `/tools/ppt-extract` | 동일 |
| PPT 배경 변경 | `/tools/ppt-background` | "PPTX" 표기 정리, **슬라이드 지정 적용 모드** 추가 |
| 이미지 압축·변환 | `/tools/image-compress` | 목표 용량(KB) 입력 모드 추가 |
| 이미지 크기 변경 | `/tools/image-resize` | 픽셀 모드에 해상도 프리셋, 프리셋 탭을 비율(1:1·16:9 등) 선택으로 개편 |

### 6.2 신규 도구 (Phase 2에서 순차 추가)

#### PPT
- **PPTX 압축** — 내부 이미지 리컴프레스 기반 용량 감소
- **슬라이드 → 이미지 일괄 변환** — 각 슬라이드를 JPG/PNG로 내보내기

#### PDF
- **PDF 워터마크 추가/제거** — 텍스트·이미지 워터마크
- **PDF 페이지 번호 추가**
- **PDF 잠금/잠금해제** — `qpdf-wasm` 등 활용
- **PDF OCR** — Tesseract.js (성능 경고 포함)
- **PDF 편집(서명·간단 텍스트 주석)** — `pdf-lib` + signature pad

#### 이미지
- **이미지 배경 제거** — `@imgly/background-removal` (ONNX)
- **이미지 크롭** — 기존 `CropSelector.tsx` 재활용, 독립 도구화
- **이미지 워터마크**
- **HEIC → JPG 변환** — `heic2any`
- **SVG → PNG 변환** — Canvas

### 6.3 제외 (현재 단계)
- PDF → Word/Excel/PPT 변환 (서버 측·품질 문제)
- 고급 PDF 편집 (상용 편집기 대체 수준)
- 사용자 업로드 갤러리 / 관리자 승인

## 7. 수익화

- **AdSense:** 적용 예정이나 **최후순위**. 디자인 단계에서 슬롯 위치만 예약.
- **로그인·결제·유료 티어:** 도입하지 않음.
- **FILE_SIZE_LIMIT:** 기존 상수 유지(비로그인 기준). 실제 일일 처리 횟수 제한은 현행과 동일하게 미적용(서버 없음).

## 8. 단계별 실행 순서

> 전략: 공통 인프라를 선행 구축한 뒤, 도구 단위로 "리디자인 + 기능 개선 + 영어 번역"을 한 번에 마이그레이션. 항상 배포 가능한 상태 유지.

### Phase 0 — 공통 인프라 (선행)
- [ ] Ontab 브랜딩 자산 (로고, 팔레트, 일러스트 시드)
- [ ] Tailwind/shadcn 우드 팔레트 커스텀 토큰 및 디자인 시스템 정립
- [ ] `next-intl` 도입 및 메시지 구조 설계 (`locales/ko.json`, `locales/en.json`)
- [ ] 공통 컴포넌트 재작업 (Header, Footer, FileUpload, ProcessingStatus, 공통 "다시 작업하기" 버튼)
- [ ] 랜딩 페이지 (3축 네비 + 책상 히어로 + 선반 그리드)
- [ ] 도구 카드 컴포넌트 (문구/공구 아이콘 세트)

### Phase 1 — 기존 10개 도구 순차 마이그레이션
각 도구당 1티켓. 도구별로 아래 작업을 한 번에 수행:
- Ontab 디자인 시스템 적용
- IMPROVEMENTS.md 해당 개선 항목 반영
- 영어 카피 번역·적용

우선순위(활용 빈도 기준 예시): `ppt-background` → `image-resize` → `image-compress` → `pdf-merge` → `pdf-split` → `pdf-pages` → `pdf-compress` → `pdf-to-image` → `image-to-pdf` → `ppt-extract`

### Phase 2 — 신규 도구 추가
브라우저 처리 난이도·활용도 순으로 추가(초안):
1. PDF 워터마크 추가/제거
2. PDF 페이지 번호
3. PDF 잠금/잠금해제
4. 이미지 배경 제거
5. 이미지 크롭 (독립 도구화)
6. 이미지 워터마크
7. HEIC → JPG
8. SVG → PNG
9. PPTX 압축
10. 슬라이드 → 이미지 일괄 변환
11. PDF OCR
12. PDF 편집/서명

### Phase 3 — SEO & 수익화
- 도구별 메타데이터 분리 (title/description/OG, KR·EN)
- JSON-LD (`WebApplication`, `SoftwareApplication`)
- `sitemap.xml`, `robots.txt` 자동 생성
- 모바일 브레이크포인트(375/768/1280) 검수
- AdSense 슬롯 적용

### Phase 4 — 문서화
- README.md 재작성 (Ontab 기준, 로컬 실행법, 도구 목록, 기여 가이드)
- 공개 릴리즈

## 10. 미결정 / 추후 결정

다음 항목은 구현 단계에서 확정한다:

- Post-Ontab 단계의 로그인·갤러리 기여 도입 여부
