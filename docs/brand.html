Logo

책상 위에 툭 던진 서류철 + "On". 헤더 마크는 고정색(테마 반전 없음 — 사용자 선택), 파비콘은 정사각·OS 다크 모드에서 반전됩니다.

설계 의도

  • 책상 위에 툭 올려둔 서류철 + 'On'
  • 설치해 여는 프로그램이 아니라, 책상에 두고 바로 집어 쓰는 가벼운 도구함
  • 헤더 마크 = 고정색(어디서나 같은 얼굴) · 파비콘만 다크 모드에서 반전

워드마크 (헤더 로고)

실제 헤더에 쓰는 잠금 조합 — 마크 + "Ontab"(Clash Display Medium). 마크 24px · 텍스트 17px · 간격 10px (Wordmark.tsx).

Ontab

여백 · 최소 크기

클리어 스페이스 = 마크 높이의 25%. 최소 표시 크기 24px(파비콘) / 28px(헤더 마크).

랜딩 브랜드 모먼트

첫 화면은 브랜드를 보여주는 자리이자 도구로 들어가는 입구. 둘의 위계가 핵심입니다.

  • 큰 "Ontab" 워드마크 = 브랜드 모먼트(가장 크고 드문 글자). 그 아래 가치 헤드라인이 가벼운 부제로 붙음.
  • 가치 헤드라인 + 신뢰 한 줄(로그인 없음 · 업로드 없음)은 조연 — "뭐 하는 곳·안전한가" 궁금한 사람만 가볍게 읽음.
  • 진입(카테고리 탭)이 주연. 가치 레이어는 탭보다 위에 서지 않고, 과한 부연으로 진입을 방해하지 않음.
  • 구체 수치·컴포넌트 규격은 DESIGN.md "Landing hero", 실제 렌더는 design-preview.html 참조.

기능 아이콘 (UI)

도구 식별용 라인 세트와 별개로, 동작·상태·입력에는 lucide 아이콘을 쓴다 (currentColor · stroke 2 · 24 그리드). 툴 아이콘(stroke 1.0 헤어라인)보다 굵고 작게(size-3 / 3.5 / 4) 쓰여 기능 신호 역할만 한다. 반복 동작은 한 글리프로 고정: 다시·재시도 = RotateCcw (RefreshCw 금지) · 다운로드 = Download · 다른 도구로 넘기기 = ArrowRight.

Motion — drop & settle

브랜드 모션 언어는 "툭 던져 안착". 셸/런처 레벨(도구를 고르고 들어가는 순간)에만 적용하고, 도구 작업 화면 안은 조용하게 둡니다. 진입과 hover lift는 같은 settle 감속을 공유합니다.

설계 의도

  • '책상' 은유를 움직임으로
  • 도구 고르기 — 책상에 툭툭 내려놓듯 카드가 차례로 안착
  • 카드 hover — 도구를 집어 드는 느낌으로 살짝 들림
  • 도구 안 — 움직임 절제, 작업에 집중
  • 결과 — 결과 카드가 툭 튀어나오듯 등장 (제목·크기·액션 버튼이 든 그 카드에만)

원칙

  1. 브랜드 모션은 셸/런처 레벨에만.
  2. 도구 안은 조용하게 — 장식 진입·transform 없음, 기능적 마이크로 피드백만.
  3. 하나의 settle 성격 — 진입과 hover lift가 같은 easing(--ease-settle)을 공유.
  4. prefers-reduced-motion 존중 — transform 제거, 페이드만.
  5. 결과 팝(.result-pop)은 "결과 카드"(제목·크기·액션 버튼 박스)에만. 함께 보이는 프리뷰·썸네일·결과 파일 리스트엔 적용하지 않는다.

토큰

--ease-standard: cubic-bezier(.4,0,.2,1);
--ease-settle:   cubic-bezier(.25,.8,.25,1);
--motion-fast:   250ms;   /* hover 색·테두리·버튼 lift */
--motion-base:   300ms;   /* 카드 hover lift, opacity */
--motion-settle: 500ms;   /* drop & settle 진입 */
--ease-pop:      cubic-bezier(.34,1.40,.64,1);   /* 결과 팝 리빌 */

컴포넌트 트랜지션 (도구 화면)

브랜드 진입 모션과 별개로, 도구 화면 안의 움직임은 기능적 마이크로 피드백만 허용한다(원칙 2). 전부 위 토큰을 공유하며, 새 트리트먼트도 같은 토큰을 쓴다. 이게 사이트의 모션 전부다.

  • .btn-primary · .btn-download — translateY lift + shadow · --motion-fast / --ease-standard
  • .nameplate · .handoff-action · .subtle-action — border-color · background · --motion-fast / --ease-standard
  • .dropzone — border-color · background (hover / drag) · --motion-fast / --ease-standard. busy(업로드 준비 중 — HEIC 변환·페이지 빌드)일 땐 비활성 + 구름 아이콘→Loader2 회전 + 프롬프트→"처리 중…"으로 자리 그대로 치환(별도 블록으로 레이아웃 안 밀어냄).
  • .toolcard — translateY lift (집어 드는 느낌) · --motion-base / --ease-settle
  • 진행 막대 — width · transition-[width] (선형, 진행률 반영)
  • 스피너(Loader) — rotate · animate-spin (처리 중 지속 회전). 용처: 진행 상태, dropzone busy, 라이브 미리보기 재계산 코너 배지(image-compress·pdf-compress — 화면에 남은 이전 렌더가 확정값처럼 보이지 않게).
  • .result-pop — opacity + scale 리빌 · --ease-pop 400ms (결과 카드에만)
  • 셸 진입 — .animate-drop-settle · .toolcard-enter (스태거) · --motion-settle / --ease-settle

모두 prefers-reduced-motion에서 transform 제거 · 페이드만 남긴다(원칙 4). 새 모션은 여기에 등재한다.
