v5 반영
① 변경하기 = 상단 스트립 오른쪽 고정(전 도구 통일 · 불가침). 미리보기만 본문으로.
② 선택한 배경 · 현재 배경 미리보기를 가로로 나란히. 둘 다 PPT 비율(16:9/4:3) 반영 · 위로 붙어 아래로 늘어남.
③ 미리보기 호버 → 돋보기(brand 규격: 24그리드·stroke 1.0) → 클릭 시 오른쪽 영역을 채우는 확대, X로 닫기.
④ 현재 배경: 체크박스(좌상단)↔적용범위 ‘선택’+범위 자동입력 · 화살표(좌하단) · ‘n장’(우하단) · dedup 3종.
⑤ 적용 범위 = 전체/마스터/선택, ‘선택’ 시 텍스트 입력.
⑥ 완료 시 → 스트립 변경하기 사라지고(idle 전용) 오른쪽 패널이 통일 결과카드로, 왼쪽 갤러리 유지.
