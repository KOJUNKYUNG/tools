@AGENTS.md

## Workflow

Read `docs/agents/workflow.md` before starting a feature, fix, or tool polish; before verifying UI; and before review, push, or PR. It sets the issue vs direct track, the `pnpm verify` gate, built-in-browser UI checks, which `code-review`, and the ship steps.

## Agent skills

### Issue tracker

Issues live in GitHub Issues (`gh issue`). See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
